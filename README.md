# Нейропатруль

Одностраничный сайт рубрики «Нейропатруль» с канала AI Native Сямыч: тесты локальных нейронок на MacBook и вердикт **ЗБС** или **ОПУЩЕН**.

Сайт: https://nikitakashin.github.io/neuro-patrouille/

Чистый HTML, CSS и JS, без сборки. Таблица строится из `data/subjects.json`.

## Как добавить строку

Открой `data/subjects.json` и добавь объект в массив `subjects` (запятая между объектами, верстку трогать не надо):

```json
{
  "id": "my-model",
  "name": "Название модели",
  "vendor": "Кто сделал · параметры · лицензия",
  "version": "Q4_K_M",
  "size": "14.5 ГБ",
  "size_gb": 14.5,
  "runtime": "llama.cpp, OpenCode",
  "speed": "77 ток/с",
  "speed_tps": 77,
  "memory": "свободно 2 ГБ",
  "test": "Что именно гонял",
  "verdict": "zbs",
  "comment": "Короткий комментарий.",
  "tested": "2026-10-22",
  "episode": "https://www.youtube.com/shorts/..."
}
```

Поля:

| Поле | Что это |
|---|---|
| `id` | любое уникальное латиницей |
| `name`, `vendor`, `version` | подопытный, кто сделал, версия или квантование |
| `size`, `size_gb` | размер текстом и числом в ГБ (число нужно для сортировки) |
| `runtime` | чем и на чём запускал |
| `speed`, `speed_tps` | скорость текстом и числом токенов в секунду (для сортировки). Для не-LLM можно `null` |
| `memory` | сколько памяти съело |
| `test` | что тестировал |
| `verdict` | `zbs` (ЗБС), `fail` (ОПУЩЕН) или `wip` (в процессе) |
| `comment` | пара предложений |
| `tested` | дата `ГГГГ-ММ-ДД` или `null` |
| `episode` | ссылка на выпуск (`https://www.youtube.com/shorts/<id>`) или `null`: тогда кнопка «Все выпуски» ведёт на плейлист Нейропатруля |

Чего не мерил, пиши `"—"` (текст) или `null` (числа). Цифры только свои.

Вверху файла `updated` и `machine`: дата и на чём тестируешь.

Потом:

```bash
git add data/subjects.json
git commit -m "Подопытный: название"
git push
```

Страница обновится через минуту-две.

## Локально

```bash
python3 -m http.server 8000
```

Открыть http://localhost:8000. С диска (`file://`) таблица не загрузится: браузер не даёт читать JSON.

## Что где

- `index.html`: разметка
- `assets/style.css`, `assets/app.js`: стили и таблица (сортировка, фильтр по вердикту, поиск)
- `assets/*.webp`: плашки вердиктов, `assets/og.png`: превью для соцсетей
- `data/subjects.json`: подопытные
